# Registration By Site

## Installation

Install the plugin ZIP file using the Plugin Dashboard.

## Setup

1. Navigate to **District Management → Registration Count Settings**
2. Set the default class size per grade and the default teacher count per grade
3. Click **Populate Teacher Counts** to apply the defaults to all elementary schools
4. Make manual adjustments to each school's teacher count and assistant teacher count as needed
   > Each added assistant teacher adds 10 to the maximum student count for that grade

## Running the Report

Navigate to **Data and Reporting → Reports → Registration By Site** and select **Elementary**
